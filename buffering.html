Buffering

A survivor pool app for watching CBS Survivor with friends.

About

Buffering is a mobile and web application that lets you compete with friends in a survivor pool while watching CBS Survivor. Each week, pick a cast member you think will survive. Pick wrong and you're out.

How It Works

  • Create or join a pool with friends using a share code
  • Each week, pick a cast member you think will survive
  • You can only pick each cast member once per season
  • If your pick is eliminated, you're out of the pool
  • Last player standing wins
